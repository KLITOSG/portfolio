# CV Portfolio

A responsive personal portfolio website created to present my profile, education, technical skills, selected frontend projects, and contact information in a clean and accessible layout.

## Featured Projects

### Calculator App

A responsive calculator application designed with a centered user interface and mobile-friendly controls. The project uses JavaScript and jQuery to update the calculator display, handle user input, and store the latest calculation with `localStorage`.

Technologies used:
- HTML5 for the page structure
- CSS3 for layout, styling, centering, and responsive design
- JavaScript for calculator logic and browser storage
- jQuery for DOM updates and interface handling

### Rock Paper Scissors

An interactive browser game that allows the user to play manually against a randomized computer opponent or activate Auto Play for continuous rounds. The project includes image-based move buttons, persistent score tracking, and a responsive layout for desktop and mobile screens.

Technologies used:
- HTML5 for semantic content and controls
- CSS3 for responsive styling, layout, and visual states
- JavaScript for game logic, DOM updates, event handling, automated rounds, score management, and random move generation
- localStorage for saving the game score between sessions

### Todo List App

A responsive task management application designed to help users create todo items with due dates, remove completed tasks, and keep their list available after page refresh through a clean, centered browser interface. The project demonstrates practical DOM manipulation, form handling, browser storage, and responsive layout techniques using JavaScript.

Technologies used:
- HTML5 for semantic structure and form controls
- CSS3 for centered layout, responsive design, and visual styling
- JavaScript for todo list logic, DOM rendering, and user interaction
- localStorage for preserving todo items between browser sessions

### Remote Job Finder

A Python-powered web app that aggregates remote job listings from multiple sources and matches them against a user's saved preferences. It includes a dashboard, private Saved and Applied job tracking, optional push and email alerts, scheduled job checks, and a progressive web app setup.

Technologies used:
- Python for the web app, job source integrations, and background worker
- HTML, CSS, and JavaScript for the dashboard and progressive web app
- Supabase Auth and Postgres for authentication and cloud data
- GitHub Actions for scheduled job checks
- Render for hosting

[View Remote Job Finder on GitHub](https://github.com/KLITOSG/remote-job-finder) · [Deployment guide](https://github.com/KLITOSG/remote-job-finder/blob/main/DEPLOYMENT.md)
